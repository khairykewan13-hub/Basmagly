# 🚀 Basmagly (بصمجلي)
> **The Core of Every Study** — البوابة الأكاديمية الذكية لطلاب الفرقة الثانية (2026 - 2027)

منصة دراسية متكاملة تجمع كل محاضرات، سكاشن، ملخصات، وكبسولات مواد الترم الأول في مكان واحد مع مزامنة حية وتلقائية مع Google Drive.

---

## 🌟 المميزات الرئيسية
* **الدخول المباشر:** تصفح فوري لكروت المواد الـ 8 دون شاشات تسجيل أو اختيار مجموعات معقدة.
* **طوارئ ليلة الامتحان (Panic Mode ⚡):** فلترة ذكية تركز على كبسولات الميدتيرم، القوانين المجمعة، والشيتات المحلولة.
* **حاسبة درجات الفاينال (Target Grade Calculator 🎯):** لحساب أعمال السنة والدرجة المطلوبة في الفاينال لضمان A أو A+.
* **كشكول الملاحظات الذاتي (Auto-saved Scratchpad 📝):** مساحة لتدوين ملاحظات وتنبيهات الدكتور تُحفظ تلقائياً في المتصفح.
* **النسخة الاحتياطية (JSON Backup & Restore 💾):** تصدير واستيراد التقدم ونقله بين الأجهزة بدون حسابات.
* **مؤقت بومودورو للتركيز (Pomodoro Timer ⏱️):** جلسات تركيز 25 دقيقة + 5 دقائق راحة.
* **مزامنة حية مع Google Drive (Live Auto-Sync 🔄):** عبر Google Apps Script Web App API مجاني وبدون تكلفة.
* **3 أوضاع عرض:** الوضع الداكن (Dark) · الوضع الفاتح (Light) · وضع القراءة الدافئ (Sepia).
